2. Description of Educational Services

HiVocab is an educational platform providing English language learners with intelligent tools to acquire academic vocabulary and master reading comprehension:

  • Over 66,000 standardized vocabulary entries with IPA phonetics, parts of speech, and contextual example sentences extracted from Cambridge IELTS (10–21) and IELTS Actual Tests (Vol 1–9).
  • Scientific memory optimization using the SuperMemo-2 (SM-2) Spaced Repetition algorithm.
  • Active Reading with Curtain Mode (bilingual parallel reading with interactive translation masks).
  • Computer-Based Test (CBT) simulation for national high school graduation exams (THPT Quốc Gia).
