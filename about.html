Master Academic English & IELTS with HiVocab

HiVocab (https://hivocab.site) is an intelligent, self-paced web learning application designed to help students master English vocabulary, enhance reading comprehension, and prepare for academic exams through scientific Spaced Repetition (SRS).

Core Application Features

Built to maximize long-term memory retention and practical language mastery.

update

Spaced Repetition System (SRS)

Implements the SuperMemo-2 (SM-2) memory algorithm. The app automatically schedules flashcard reviews right before words are forgotten, optimizing long-term retention with minimal daily practice.

menu_book

Curated Exam Vocabulary

Contains over 66,000+ standardized vocabulary items extracted from Cambridge IELTS (books 10–21), IELTS Actual Reading Tests, Destination B1–C2, and Oxford 3000 academic word lists.

auto_stories

Active Bilingual Reading

Interactive bilingual reading comprehension with "Curtain Mode" translation masks, sentence alignment, and instant tap-to-translate lookups to build real-world reading fluency.

timer

Exam Simulator (THPT)

Timed practice test simulations based on official Vietnamese National High School Graduation (THPT Quốc Gia) English exams, featuring instant scoring and question explanations.

collections_bookmark

Personal Word Notebook

Allows learners to bookmark difficult vocabulary, take notes, track mastery levels (Level 0 through 5), and review words by category or search term.

sync

Cloud Progress Sync

When signed in via Google, study streaks, memorized flashcards, and test history synchronize instantly across desktop and mobile devices.

security

Google OAuth & Data Privacy Transparency

Transparent explanation of data collection and Google user data handling.

HiVocab provides an optional Sign in with Google feature to allow users to save their learning progress and access their vocabulary lists across multiple devices.

1. Requested OAuth Scopes

HiVocab requests access only to the minimum basic identity scopes:

openid: Used to verify user identity via standard OpenID Connect.
.../auth/userinfo.email: Used to create and identify the user's account in our database.
.../auth/userinfo.profile: Used to display the user's name and avatar in their study profile.

2. How Google User Data Is Used

  • To create your personalized learning profile and calculate your daily Spaced Repetition review schedule.
  • To sync your bookmarked vocabulary, study streaks, and quiz results between sessions.
  • We never access your Google Drive files, contacts, calendar, or emails.

3. Google API Limited Use Verbatim Compliance

"HiVocab's use and transfer to any other app of information received from Google APIs will adhere to Google API Services User Data Policy, including the Limited Use requirements."

4. User Rights & Data Deletion

Users can revoke HiVocab's access to their Google Account at any time via Google Account Permissions. You can also request complete deletion of your account and all associated study data within 7 business days by emailing support@hivocab.com.
